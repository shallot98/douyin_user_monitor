调用文档

                
路径 · 鉴权 · 字段 · 错误信封 · CDN 注意

              

            

            

              
端点

              
    
                
  • POST /api/monitor/parse — JSON body {"text":"...","include_raw":false}
    • 
                
  • GET /api/monitor/parse?text=...&include_raw=0 — 便于 curl / 浏览器试玩
    • 
                
  • 本页：GET /api/monitor/api/dashboard
    • 
              


              
鉴权

              

                与全局监控 API 相同：环境变量 DYMON_API_KEY。请求头 X-API-Key: <key>，或 query ?api_key=<key>。
                未配置 key 时不校验；配置后缺少 key 返回 401。
              


              
curl 示例

              
# POST
curl -sS -X POST 'http://HOST/api/monitor/parse' \
  -H 'Content-Type: application/json' \
  -H 'X-API-Key: YOUR_KEY' \
  -d '{"text":"https://v.douyin.com/xxxxx/","include_raw":false}'

# GET
curl -sS 'http://HOST/api/monitor/parse?text=https%3A%2F%2Fv.douyin.com%2Fxxxxx%2F' \
  -H 'X-API-Key: YOUR_KEY'

错误信封

              

                业务错误通常 HTTP 400，body 为 {code, message, router, params}（与现有 monitor 一致）。
                常见 message：未找到有效抖音链接、无法解析作品 ID、获取作品详情失败、Cookie/上游异常透传。
              


              

                CDN / Cookie 注意

                1. 返回的直链常带签名，短时有效，请立即下载，勿持久化依赖。

                2. 解析依赖当前 crawler 配置 Cookie / Cookie 池；失效时错误信息会透出，需先在 Cookie 池测活。

                3. 服务端不落盘、不代理流式下载；限流 / 独立 API Key 请自备网关。
