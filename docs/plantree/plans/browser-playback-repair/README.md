# 浏览器播放修复

Role: entrypoint
Mode: execute-ready
Status: In Progress — 上传与网站发布已恢复，普通批量正在执行
Date: 2026-09-14

## 目标与约束

按用户“执行修复”的授权处理网站实际选中的播放文件。原片保持原内容和原归档用途，兼容播放文件保存在 D2；历史视频不得下载到项目本机进行修复。

全量清单使用 2026-09-13 14:14:19 +08:00 的固定快照：600 个账号，其中 538 个有视频，共 12,768 条视频。后续增量监控产生的新作品不混入该快照。

## 统计结果

全部 12,768 条完成检查，6,597 条存在目标浏览器播放障碍或文件异常，涉及去重 466 个账号：5,717 条 HEVC、866 条当前路径失败、10 条空文件、2 条仅音频、1 条加密封装、1 条容器长度不一致。HEVC 结论适用于不支持 HEVC 的目标浏览器；其余 6,171 条只确认 H.264 编码，逐条完整浏览器播放没验证。

866 条路径失败已全部定位、安装精确映射并通过真实网页 Range/索引复核：561 条为 H.264 候选，305 条仍为 HEVC。替换该组的失效地址分类后，固定快照为 6,732 条 H.264 候选、6,022 条 HEVC 和 14 条特殊记录；这不代表全部通过完整浏览器验收。完整原始清单见[统计报告](../../../../runtime/web-playback-inventory-20260913/report.md)，部署结果见[执行证据](evidence/execution.md)。

另检查 1,211 个已有封面引用，找到并修复全部 17 个失效路径，17 张图片均通过真实浏览器解码。当前共安装 883 条映射。

`boh` 已部署 12,410 条去重作品的可恢复队列：普通队列 12,400 条，加上 10 条已验证可用来源的损坏原片恢复。队列包含编码兼容、启动速度与封面优化，不能把全部条目计为“无法播放”。固定快照另有 340 条无需当前改动、14 条当前状态中已消失的记录、4 条仍无可用恢复方案的特殊记录。
