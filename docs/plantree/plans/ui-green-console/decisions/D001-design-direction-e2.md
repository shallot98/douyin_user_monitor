# D001 · Design direction = E2 Green Console Refined

## Decision
Production UI restyle targets **E2** (`ui-mockups/06-green-console-refined.html` + mobile companion), inspired by the user-provided dark-green console reference.

## Context
- Original mobile UX: desktop sidebar/admin layout, cramped on phone
- User rejected boxy number grids as abrupt
- E2 softens metrics via typography + dividers, green monochrome, list health rows

## Consequences
- Dark theme only for this plan
- Accent = mint/sage green, not indigo primary from old Inter admin theme
- Mockups are acceptance reference, not runtime code
